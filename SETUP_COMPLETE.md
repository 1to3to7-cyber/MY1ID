## ⚠️ Known Issues & Solutions

### Issue: "Failed to load resource: 400 Bad Request"
**Cause**: Supabase credentials not configured
**Solution**: Add `.env.local` with Supabase credentials
```env
NEXT_PUBLIC_SUPABASE_URL=your-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-key
```

### Issue: "Middleware file convention is deprecated"
**Cause**: Using old middleware pattern
**Status**: Warning only - functionality works
**Future**: Will migrate to proxy pattern

### Issue: PowerShell execution policy
**Solution**: Already handled with execution policy bypass
